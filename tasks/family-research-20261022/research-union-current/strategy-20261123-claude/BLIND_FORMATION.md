# How a version is formed (Claude's first message of the strategy step, 2026-11-23)

The shared task asked for this first: how a version is formed blind to the trade day it is tried on. Greg ruled on
it before it was written, in this session: **"Use all 4 days to make strategies"**. So this file says what that
ruling means, plainly, and what is kept in place of blindness.

## Which trade days each version is formed on, and tried on

- FORMED ON: all four trade days (Oct 2, 3, 17, 18, 2023), every one of the fifteen versions.
- TRIED ON: only those four exist. A try of a version on any of them is therefore NOT a blind test: the version
  was formed on that trade day. It is a record of how the version behaves, event by event, on the tape it was
  formed on. Nothing more is claimed from it.
- A BLIND TEST needs a trade day beyond the four (none is held, and only the four enter any calculation) or live.
  Every version stays a hypothesis: provisional until live.

## What is kept in place of blindness

1. NO NUMBER OF CLAUDE'S IS IN ANY VERSION. A version uses only states the tape itself makes exact: which side of
   zero a stored line stands on; every order of a level filled, or every order pulled; a second step exists or it
   does not; two things are in the same exchange event or they are not. Nothing was tuned to the four trade days,
   because there is nothing in a version to tune. Where a number would be needed it is left open as Greg's.
2. EVERY VERSION IS WRITTEN DOWN AND PUSHED BEFORE ANY TRY, with what would show it wrong written beside it
   (`VERSIONS.md`). A change after a try is a new numbered revision; the old one is kept.
3. EVERY COUNT IS READ PER TRADE DAY AND PER CELL, never pooled. Where the four disagree it is said in the version
   itself (one example: the exhaustion line at a first step reads the other way in three cells, all on trade day
   Oct 3 and all upward).
4. WHAT IS BUILT IN IS SAID IN EVERY VERSION, so that a thing true by construction is not read as a finding
   (a buy that takes out the best offer steps it in the same exchange event; a trade leg's first print is already
   in both lines; a hump that begins as old trades leave carries no direction).
5. THE LEAKAGE GATE comes before any try: what a version knows at a tick must not change when later ticks change.
