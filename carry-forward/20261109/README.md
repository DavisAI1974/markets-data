Entries must receive defined platform paper trials; missing rules cannot be replaced with invented thresholds or hindsight inputs. Preserve every original target, horizon, side, state and denominator when doing that work.

They do not override the user's all-paper instruction or later source corrections. A partial prefix still needs its own causal trigger; the instruction to include it does not make a future state available at an earlier clock. Do not turn a failed historical result into an exclusion.
